# Daily Maintenance

Run a version check across all package manifests and upgrade every dependency to
its latest version — including major bumps. Staying on the latest is the goal;
do not skip majors.

This lives here rather than in `CLAUDE.md` on purpose. As prose in a file that
loads into every session it read as a standing licence to bump majors in the
middle of an unrelated bugfix. As a command it runs when it is asked for.

1. Check `package.json` (root) and the nested manifests — `plugin/package.json`
   (generated by `scripts/build-hooks.js`, so change its source there) and
   `examples/sdk-node/package.json` — with `npm outdated`.
2. Upgrade every package to `latest` (`npm install <pkg>@latest` per package, or
   `npx npm-check-updates -u && npm install`). Bump majors too.
3. Run `npm audit fix` to resolve advisories.
4. Run `npm run build-and-sync`, then verify the worker starts and the tests
   pass. Fix breakage caused by a major bump in the same change.
5. Commit the updated `package.json` files and the regenerated `plugin/bun.lock`.
   `package-lock.json` is gitignored — do not try to commit it.
